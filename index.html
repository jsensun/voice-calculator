手机语音输入的限制与说明（点开看）

手机浏览器对语音识别有硬性限制，本应用已针对性处理：

  • 微信里打不开语音：微信内置浏览器基本不支持语音识别，麦克风也被它拦截。请点右上角 ⋯ → 在浏览器中打开（Safari / Chrome），再用麦克风。
  • 必须用 HTTPS：麦克风权限只在 https:// 或 localhost 下可用，用 file:// 直接打开或普通 http 网站将无法收音。
  • 必须由点击触发：iOS / 安卓都要求用户主动点一下麦克风才开始识别，不能自动启动。
  • iOS 不能长时间连续识别：Safari 一次识别约几秒后会自动停止，说完后松手即可，下方输入框可手动修正。
  • 识别不一定准：方言、环境噪音会导致数字或运算符识别错误，请核对输入框内容再计算。
  • 部分浏览器不支持：若提示「当前浏览器不支持语音」，可直接用键盘或输入框里的系统麦克风按钮。
